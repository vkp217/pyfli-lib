numerical_jacobian(model, params, rel_step=1e-4, abs_step=1e-8)[source]#

Central-difference Jacobian dmu/dtheta of a batched model.

Parameters:

  • model (Callable) – model(params) with params (P, K) returning channel means (P, T).

  • params (np.ndarray) – Parameter vectors (P, K) (or (K,) for a single one).

  • rel_step (float) – Step for parameter k is max(rel_step * |theta_k|, abs_step).

  • abs_step (float) – Step for parameter k is max(rel_step * |theta_k|, abs_step).

Returns:

Jacobian of shape (P, K, T).

Return type:

np.ndarray

fisher_information(model, params, noise='poisson', sigma=None, jacobian=None, rel_step=1e-4, abs_step=1e-8)[source]#

Fisher matrices (P, K, K) of a batched model at params (P, K).

Parameters:

  • model (Callable) – model(params) -> channel means (P, T).

  • params (np.ndarray) – Parameter vectors (P, K).

  • noise (str) – "poisson" (counts; the means come from the model) or "gaussian" (needs sigma).

  • sigma (Any) – Noise standard deviation for noise="gaussian".

  • jacobian (np.ndarray | None) – Analytic Jacobian (P, K, T); computed numerically when None.

  • rel_step (float) – Finite-difference steps (see numerical_jacobian()).

  • abs_step (float) – Finite-difference steps (see numerical_jacobian()).

Return type:

ndarray
