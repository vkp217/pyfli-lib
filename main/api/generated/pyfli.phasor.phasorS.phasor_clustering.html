phasor_feature_matrix(G, S, mask=None, harmonics=(1,), polar=False, extra_maps=None)[source]#

One feature row per pixel from multi-harmonic phasor coordinates.

Parameters:

  • G (np.ndarray) – Phasor coordinates, (n_harmonics, H, W) or (H, W).

  • S (np.ndarray) – Phasor coordinates, (n_harmonics, H, W) or (H, W).

  • mask (np.ndarray | None) – Pixels to use ((H, W) boolean); default all. Pixels with any non-finite feature are dropped as well.

  • harmonics (iterable of int) – 1-based harmonics to include.

  • polar (bool) – Use phase atan2(S, G) and modulation sqrt(G^2 + S^2) instead of G / S.

  • extra_maps (dict[str, np.ndarray] | None) – Additional (H, W) maps appended as features (e.g. {"log_intensity": np.log1p(decay.sum(-1))}).

Returns:

(X, pixels, names): features (n_pixels, n_features), the (row, col) coordinates of every row, and the feature names.

Return type:

tuple[np.ndarray, np.ndarray, list[str]]

cluster_summary(G1, S1, label_map, phasor, param_maps=None, background=-1, intensity=None)[source]#

Per-cluster summary of a first-harmonic phasor image: pixel count, mean G / S, the phase and modulation lifetimes of the cluster-mean phasor – computed with the given pyfli.phasor.phasorS.PhasorAnalyzer (compute_lifetime / compute_modulation_lifetime) – and the mean of every map in param_maps (e.g. the simulator’s ground-truth maps) inside the cluster. Pixels labelled background are ignored.

By default every pixel counts equally. Pass the photon-count image as intensity to weight the mean phasor by photons instead: it is then exactly the phasor of the cluster’s summed decay (phasors add with intensity weights).

Parameters:

  • G1 (ndarray)

  • S1 (ndarray)

  • label_map (ndarray)

  • phasor (Any)

  • param_maps (dict[str, ndarray] | None)

  • background (Any)

  • intensity (ndarray | None)

Return type:

DataFrame
