class PriorBank(state, ctx, n, seed, uniform_share=0.3)[source]#

Bases: object

Simulated pixels from a broad proposal, re-weighted to any candidate set of Beta priors.

The bank is a defensive mixture: uniform_share of the pixels come from flat Beta(1, 1) priors on the current supports, the rest from the current priors widened about 4x in variance. For target priors pi each pixel gets the weight pi(theta) / q(theta), so the statistics of any candidate prior are obtained without re-simulating. IRF, noise and photon priors stay fixed inside one bank.

Parameters:

  • state (CalibrationState)

  • ctx (ObjectiveContext)

  • n (int)

recenter_tau2_support(state, margin=0.3)[source]#

Move tau2_beta_range to the fitted prior’s 0.1-99.9 % range plus margin on each side, keeping the prior’s mean and SD. Initial supports from noisy per-pixel fits are usually far too wide, which wastes the bank and makes the Beta very skewed.
