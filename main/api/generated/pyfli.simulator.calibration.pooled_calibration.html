covering_background(sessions, library, n_samples, rng, q=0.995)[source]#

One dark-count rate cannot reproduce experiments whose backgrounds differ 100-fold, and too much background pulls the raw phasors of clean experiments out of the simulated cloud. The combined config therefore uses the lowest dark-count rate and gets the rest from the per-pixel IRF baseline b ~ U(0, b_max_k) (background proportional to signal). Background belongs to the detector channel, so each library IRF k gets its own b_max_k, chosen so that experiment k’s background fractions are reached. A single shared range would make the low-background channel’s clean pixels rare.

Parameters:
