Bases: object

Everything the calibration needs.

Parameters:

  • data_path (str) – Raw 3D decay data (.sdt, .ptu, .tif, .npy, …), loaded via pyfli.io.DataOperations.

  • detector_type (str) – “continuous” (gated/ICCD-like) or “discrete” (TCSPC photon counting).

  • model_type (str) – “bi_exponential” or “mono_exponential”.

  • irf_path (str | None) – Experimental IRF. When omitted the IRF is simulated with pyfli.simulator.IRFGenerator.gaussianExpIRF and its parameters are optimised.

  • mask_path (str | None) – Boolean mask of sample pixels. When omitted, one is derived automatically.

  • reference_path (str | None) – Optional parameter maps (AlliGator folder, SPCImage folder, or a pyfli session .npy file / folder) used to initialise and regularise the priors.

  • target_coverage (float) – Required fraction of experimental pixels inside the simulated distribution for every coverage statistic (raw phasors h=1/2, photons, rising edge, background); see coverage. After the best-fit calibration the config is widened until this is reached, so that the experiment is a subset of what the simulator produces. 0 keeps the best-fit config.

  • n_coverage_pixels (int) – Simulated pixels per coverage check.

  • max_coverage_iter (int) – Maximum number of widening steps.
