Forward model lambda(theta) via ParamToDecay, amplitude pinned to the measured total.

background (v_shift) is None, a value, a map or "auto" (Poisson MLE, seeded from pre-onset bins); background_key takes it from the posterior instead. h_shift (onset, ns) is None, a value or a map; h_shift_key takes it from the posterior; excitation/gate_width are the forward-model options of ParamToDecay. Called as forward(params, y).
