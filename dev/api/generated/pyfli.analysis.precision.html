crb_for_cv_bins(cv_df, tau_map, photon_map, irf, laser_period, mask=None, cluster_mask=None, cluster_names=None, n_photons_map=None, background_per_bin=0.0, fit_background=False)[source]#

Ideal CV for every photon-count bin of a pyfli.data_vnp.CVPlot.compute() table, so it can be plotted against (or merged with) the measured curves.

Bin membership is rebuilt from the table’s bin_low / bin_high edges on photon_map (the same photon map given to CVPlot), per cluster when the table has clusters. Within a bin, the per-pixel CRB variances are averaged, so cv_crb = sqrt(mean((cv_i * tau_i) ** 2)) / mean(tau_i) – the CV an ideal estimator would show across those pixels, excluding the true lifetime spread.

Parameters:

  • cv_df (pd.DataFrame) – Output of CVPlot.compute (columns cluster, bin_rank, bin_low, bin_high, bin_center).

  • tau_map (np.ndarray) – True lifetime per pixel (ground truth), (H, W).

  • photon_map (np.ndarray) – Photon map used for binning in CVPlot (e.g. decay.sum(axis=-1)).

  • irf (ndarray) – See crb_lifetime_cv().

  • laser_period (float) – See crb_lifetime_cv().

  • mask (np.ndarray | None) – Pixel mask used in CVPlot.

  • cluster_mask (ndarray | None) – The same cluster labels and names given to CVPlot, if any.

  • cluster_names (dict[int, str] | None) – The same cluster labels and names given to CVPlot, if any.

  • n_photons_map (np.ndarray | None) – Expected signal photons per pixel for the bound; defaults to photon_map. Pass the ground-truth photon_count_map to exclude dark counts.

  • background_per_bin (float) – See crb_lifetime_cv().

  • fit_background (bool) – See crb_lifetime_cv().

Returns:

One row per (cluster, bin): cluster, bin_rank, bin_center, tau_true, n_signal, cv_crb and F_crb (cv_crb * sqrt(bin_center), directly comparable with a measured cv * sqrt(bin_center)). Merge with the measured table on ["cluster", "bin_rank"].

Return type:

pd.DataFrame

crb_lifetime_cv(tau, n_photons, irf, laser_period, background_per_bin=0.0, fit_background=False)[source]#

Ideal (Cramér-Rao) coefficient of variation of the lifetime, sigma_tau / tau.

The unknowns are the photon count N and tau (plus the background level when fit_background is True, which is what NLSF / MLE fits with a free offset v_shift do). The background level itself always enters the Poisson noise.

Parameters:

  • tau (float | np.ndarray) – True lifetime (ns) and expected number of detected signal photons; broadcast against each other.

  • n_photons (float | np.ndarray) – True lifetime (ns) and expected number of detected signal photons; broadcast against each other.

  • irf (np.ndarray) – IRF of shape (T,), or one IRF per value with shape S + (T,).

  • laser_period (float) – Laser repetition period in ns.

  • background_per_bin (float | np.ndarray) – Expected background (dark) counts per gate, e.g. the simulator’s dcr.

  • fit_background (bool) – Treat the background level as an extra unknown parameter.

Returns:

Ideal CV with the broadcast shape of the inputs; NaN where tau <= 0, N <= 0 or an input is not finite. CV * sqrt(N) is the F-value.

Return type:

np.ndarray

run_monte_carlo(irf, tau, photon_counts, n_repeats=200, methods=('NLSF', 'MLE', 'mean_arrival', 'phasor'), laser_feq=80.0, dcr=0.0, max_iter=1000, n_jobs=-1, seed=None, crb_fit_background=None)[source]#

Monte Carlo precision of each method against photon count, for one fixed lifetime.

For every photon count N in photon_counts, n_repeats decays are simulated, every method estimates the lifetime of every decay, and the spread of the estimates is summarized. The Cramér-Rao bound for the same tau, N, IRF, window and background is added for reference.

Parameters:

  • irf (np.ndarray) – IRF trace (T,).

  • tau (float) – True lifetime (ns) shared by all copies.

  • photon_counts (iterable of float) – Expected signal photons per decay (each >= 10).

  • n_repeats (int) – Copies per photon count.

  • methods (iterable of str) – Any of "NLSF", "MLE", "mean_arrival", "phasor", "phasor_bin_corrected".

  • laser_feq (float) – Laser repetition rate in MHz.

  • dcr (float) – Dark counts per gate (0 disables them).

  • max_iter (int) – Optimizer iteration budget for the fits.

  • n_jobs (int) – Parallel fitting jobs.

  • seed (int | None) – Base seed; photon count i uses seed + i.

  • crb_fit_background (bool | None) – Whether the bound treats the background as unknown (as fits with a free offset do). Defaults to dcr > 0.

Returns:

One row per (method, N): method, n_photons, n_detected (mean total counts), n_valid, tau_true, tau_mean, tau_std, bias, rel_bias, cv (std / mean), F (cv * sqrt(N)), cv_crb, F_crb and efficiency ((cv_crb / cv) ** 2, see fisher_crlb.estimator_efficiency(); 1 means the method reaches the bound).

Return type:

pd.DataFrame
