pyfli.io.spad_hdf5#

Discover and read SPAD data from arbitrary HDF5 structures.

This module belongs to pyfli.io and provides structure-aware HDF5 discovery without requiring detector-specific group or dataset names. Explicit metadata and user hints take priority over structural inference, while ambiguous layouts are reported instead of selected silently.
