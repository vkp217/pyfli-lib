unwrap_phases(z, frequency_hz, t0_guess_ns=0.0)[source]#

Phases phi_k of calibrated phasors z (K, ...), unwrapped beyond the principal value. Since phi_k lies in [k omega t0, k omega t0 + pi/2), each harmonic is taken within pi of k omega (L + U) / 2 + pi/4, the centre of the bracket [L, U] of eq. 7 built from the lower harmonics; this is unique while k omega (U - L) < 3 pi / 2. Unwrapping against k phi_1 (paper section 9) instead fails for long lifetimes at k >= 4. Harmonic 1 is centred on t0_guess_ns and needs |t0 - t0_guess| < 3T/8.

Parameters:

  • frequency_hz (float)

  • t0_guess_ns (ArrayLike)

Return type:

ndarray

combine_offsets(t0_k, cov, full_covariance=True, tau_k=None)[source]#

Generalised least-squares mono-exponential test across harmonics (paper eq. 10). With t0_k only, one parameter t0 on K observations (dof = K - 1); with tau_k and a joint cov from offset_covariance(..., include_lifetime=True), two parameters (t0, tau) on 2K observations (dof = 2K - 2), which also tests that the modulation lifetimes agree. full_covariance=False drops the cross terms.

bi_exponential_offset(z, noise, frequency_hz, t0_guess_ns=0.0, margin_ns=0.1, n_jobs=-1)[source]#

Per-pixel offset of a bi-exponential decay from K >= 3 harmonics. Theorem 1 makes t0 unidentifiable for an arbitrary completely monotone decay, but under the bi-exponential model z_k = e^{i k omega t0} (A / (1 - i k omega tau1) + (1 - A) / (1 - i k omega tau2)) the 2K real data determine the four unknowns (t0, tau1, tau2, A). Each pixel is fitted by weighted least squares, whitened by the shot-noise covariance of phasor_noise(), with t0 inside its bracket (offset_bracket()) widened by margin_ns. A = 1 is the mono estimate.

Returns:

"t0", "t0_se", "tau1", "tau2", "alpha1" (photon fraction of tau1), "chi2" and "reduced_chi2", each (...) (NaN where the noise is undefined), "dof" = 2K - 4 and "n_params" = 4.

Return type:

dict[str, Any]

Parameters:

  • z (ArrayLike)

  • noise (dict[str, ndarray])

  • frequency_hz (float)

  • t0_guess_ns (ArrayLike)

  • margin_ns (float)

  • n_jobs (int)

imbalance_offset(z, frequency_hz, noise=None, t0_guess_ns=0.0)[source]#

Closed-form c, tau and t0 under modulation imbalance c != 1 (paper eq. 12): weighted least squares of 1 / m_k^2 = P + Q k^2.

Parameters:

  • frequency_hz (float) – Laser repetition frequency in hertz.

  • noise (dict | None) – phasor_noise() output; gives inverse-variance weights and makes chi2 (K - 2 degrees of freedom) a test of constant c. Unweighted if None.

  • t0_guess_ns (array_like) – See unwrap_phases().

Returns:

"c", "tau" (ns), "t0" (ns, weighted mean of "t0_k"), "t0_k" (K, ...), "chi2", "reduced_chi2" (NaN for K = 2), "dof" and "n_params" (P, Q).

modulation_factor(n_counts, v_shift, n_gates, irf_counts=None, irf_v_shift=0.0)[source]#

Modulation imbalance c = (1 - beta) / (1 - beta_I) of paper eq. 3 from the constant per-gate backgrounds (the solver’s v_shift): beta = n_gates v_shift / n_counts for the sample and beta_I = n_gates irf_v_shift / irf_counts for the IRF trace. Dividing calibrated phasors by c restores c = 1 exactly.

class HarmonicOffset(analyzer)[source]#

Bases: object

Pixelwise t0 estimation and correction on top of a PhasorAnalyzer (n_harmonics >= 2; its time axis must be gate_starts() of the period 1 / frequency over which the phasors are computed).

Parameters:

analyzer (PhasorAnalyzer)

estimate(decay, irf, alpha=0.05, order=0, excess_noise=1.0, full_covariance=True, include_lifetime=False, t0_guess_ns=0.0, v_shift=None, irf_v_shift=0.0, model='mono-exponential', n_jobs=-1)[source]#

Run the full pipeline on a decay cube (H, W, T) and a 1-D or per-pixel IRF. include_lifetime tests (t0_k, tau_k) jointly (dof = 2K - 2) instead of t0_k alone (dof = K - 1; see combine_offsets()). A known per-gate background v_shift (scalar or (H, W), e.g. the solver’s v_shift_map) and irf_v_shift give c (modulation_factor()), which is divided out of the calibrated phasors and their noise. model="bi-exponential" (n_harmonics >= 3) estimates each pixel’s offset under the bi-exponential model (bi_exponential_offset()), so bi-exponential samples need no mono-exponential pixels; the chi-square test then has dof = 2K - 4.

Returns:

z (calibrated phasors (K, H, W)), t0_k, tau_k, lower, upper, cov, c, the combine_offsets() keys with t0 as t0_hat (and tau as tau_hat), accepted, t0_map, h_shift_map (solver convention, h_shift_from_t0()), theta and violations (rejected pixels whose bracket excludes t0_map). For the bi-exponential model, the bi_exponential_offset() keys with t0 as t0_hat and tau1, tau2, alpha1 as tau1_hat, tau2_hat, alpha1_hat, and cov = None.

Return type:

dict[str, Any]
