class IndependentSweepGenerator(irf_cube, base, sweep, weights, a_range, b_range, seed=None)[source]#

Bases: object

Draws every swept key independently with its weights, then simulates one pixel with pyfli’s SimGenerator. The resulting distribution is that of ConfigCombinationGenerator.sample / WeightedConfigSimGenerator (combination weight = product of per-key weights), but nothing is enumerated, so any number of experiments works. config_index in the output gives the chosen value index per key.

verify_combined(setup_path, n_sim=10000, n_exp=20000, seed=0)[source]#

For every experiment of the combined setup, the coverage (coverage_fractions()) of its sample pixels by

  • own values: the combination made of that experiment’s sweep values, i.e. its own calibration after re-expression on the common supports;

  • combined: the whole combined distribution (all combinations, with weights).

Both use the experiment’s own IRF run. The experimental pixels are re-loaded from the experiment’s data file with its calibration’s bin radius and sample mask. The table is also written next to the setup as coverage_per_experiment.csv.

Parameters:

  • setup_path (str)

  • n_exp (int)
